# Live black-box QA — https://openreview.tech

17 November 2026. Headless Chromium via Playwright 1.64.1 (Chrome for Testing 156.0.8078.4) from a Linux VM. axe-core 4.10.3. No product code was changed in this pass.

## Method

- Seeded `/`, `/docs`, every sitemap `/docs/*` page, `/changelog`, `/feedback`, `/feedback/roadmap`, `/privacy`, `/terms`, `/security`, `/login`, `/signup`, and the landing pricing CTAs (`/signup?next=…intent=starter` and `…intent=pro`).
- Followed same-origin links discovered on those pages (skipped `/api`, `/dashboard`, `/oauth`, `/invite`, `/fix`, `/r`).
- For each URL: HTTP status, viewport screenshots at **1280×800** and **390×844**, console errors, failed network requests, broken images, document overflow, overlapping/cut-off text heuristics, and axe-core (`wcag2a/aa`, `wcag21a/aa`, `wcag22aa`, `best-practice`).
- Email sign-up once on `/signup` (no OAuth). Cloudflare Turnstile became a visible checkbox; per instructions the run stopped and did not submit again.
- Screenshots: [`docs/internal/live-qa-screenshots/`](live-qa-screenshots/).

## Numbered issues

### 1. Changelog links to a 404

- **URL:** `https://openreview.tech/docs/public/fix-with-agents.md` (reached from `/changelog`)
- **Problem:** HTTP **404** “Page not found”. `CHANGELOG.md` contains `[Fix with agents](docs/public/fix-with-agents.md)`. The docs renderer rewrites that path to `/docs/fix-with-agents`; the changelog renderer does not, so the hosted changelog emits a raw markdown path that 404s.
- **Severity:** High
- **Likely source:** `CHANGELOG.md` (the href); `app/changelog/page.tsx` (Markdown has no `resolveDocLink` / `a` rewrite, unlike `app/docs/[[...slug]]/page.tsx` + `src/docs-manifest.ts`)
- **Evidence:** `docs-public-fix-with-agents.md--1280x800.png`

### 2. Privacy policy table overflows the viewport

- **URL:** `https://openreview.tech/privacy`
- **Problem:** The “Who we share information with” table is not in a scroll region. Document `scrollWidth` was **1461px** at 1280 and **1205px** at 390. On a 390px phone the **Purpose** column is clipped (`Website` / `Databa` / `AI mod` / `With yo`…). Docs pages wrap tables in `ScrollTable`; legal pages do not.
- **Severity:** High (mobile), Medium (desktop)
- **Likely source:** `legal/privacy.md` (the table); `app/legal.tsx` (no `table` → `ScrollTable` component); contrast `app/docs/[[...slug]]/page.tsx` which does wrap tables
- **Evidence:** `privacy-table--390x844.png`, `privacy-table--1280x800.png`, `privacy--390x844.png`

### 3. Cookie banner covers primary UI

- **URL:** every public page on a first visit (`ConsentBanner` in the root layout)
- **Problem:** Fixed bottom-left banner (`z-index: 60`) sits on top of page text, the privacy table, the GitLab OAuth button, and the Terms/Privacy line. On `/login` and `/signup` at 390×844, **Sign up/in with GitLab** is fully hidden until the visitor accepts or declines. Overlap heuristics also fired against docs sidebar links (“Fix with agents” vs Decline/Accept).
- **Severity:** High on `/login` and `/signup` (covers a sign-in method); Medium elsewhere
- **Likely source:** `app/consent.tsx`, `app/layout.tsx`, `app/globals.css` (`.consent`)
- **Evidence:** `login--390x844.png`, `signup--390x844.png`, `signup-after-submit--1280x800.png`, `privacy--1280x800.png`

### 4. UserJot / Turnstile CSP noise on every page

- **URL:** all 47 crawled URLs
- **Problem:** Console errors on **every** page, including those that do not embed the feedback board:
  - `collect.jotlens.com/collect` blocked by `connect-src` (94 hits)
  - `fonts.googleapis.com/css2?family=Inter…` blocked by `connect-src` (94 hits) — allowed in `style-src`, not `connect-src`
  - `cdn.userjot.com/sdk/…/app.*.css` blocked by `connect-src` (94 hits)
  - On `/login` and `/signup`, Turnstile also logs `Connecting to 'data:,' violates connect-src` and `Fetch API cannot load data:,`
- **Severity:** Medium (broken third-party telemetry/fonts for the widget; noisy console; possible missing Inter inside UserJot)
- **Likely source:** `src/security-headers.ts` (`connect-src` list); `app/userjot.tsx` and `app/layout.tsx` (widget on every page); `app/turnstile.tsx` for the `data:,` errors
- First-party document requests themselves returned 200. Next.js `?_rsc=` prefetches aborted with `net::ERR_ABORTED` when leaving a page; those are not user-facing failures.

### 5. Docs search `aria-controls` points at a missing id

- **URL:** `/docs` and every `/docs/*` page (66 axe hits)
- **Problem:** axe **critical** `aria-valid-attr-value`: the search input always has `aria-controls="{id}-results"`, but the results node is rendered only while there is a query. Empty search is an invalid ARIA reference.
- **Severity:** Medium (a11y)
- **Likely source:** `app/docs/docs-search.tsx`

### 6. Sign-in hint fails WCAG AA contrast

- **URL:** `/login`, `/signup` (and pricing CTA variants)
- **Problem:** axe **serious** `color-contrast` on `.sign-in-hint` (“We’ll email you a sign-in link…”): **3.45:1** (`#8a8a8a` on `#ffffff`, 13px). Needs 4.5:1. Color comes from `--text-ter`.
- **Severity:** Medium
- **Likely source:** `app/globals.css` (`.sign-in-hint`, `--text-ter`); copy in `app/sign-in.tsx`
- Decorative auth-art line numbers also fail contrast (2.3–2.7:1) but are `aria-hidden`; treat those as Low.

### 7. Landing “self-hosting guide” link is color-only

- **URL:** `https://openreview.tech/` at 390×844
- **Problem:** axe **serious** `link-in-text-block` on `<a href="/docs/self-hosting">self-hosting guide</a>` inside `.muted`: 1.11:1 against surrounding text and no underline. Desktop did not flag it (layout/reveal timing).
- **Severity:** Medium
- **Likely source:** `app/page.tsx` (pricing footnote); `app/globals.css` (`.muted` / in-paragraph links)

### 8. Mobile site nav clips “Roadmap” / “Feedback” / “GitHub”

- **URL:** all chrome pages at 390×844 (`/`, `/docs/*`, `/privacy`, `/feedback`, …)
- **Problem:** The header row is `flex-wrap: nowrap; overflow-x: auto` with no scrollbar/peek affordance. The screenshot shows **“Roa”** / **“Change”** with Roadmap, Feedback and GitHub off-screen. Items are reachable by swiping the nav, but that is not obvious. On `/` the Pricing link also pushes Changelog off-screen.
- **Severity:** Medium
- **Likely source:** `app/site-chrome.tsx` (nav link set); `app/globals.css` (`@media` `.site-nav` around the 760px break)
- **Evidence:** `home--390x844.png`, `privacy--390x844.png`, `docs-quickstart--390x844.png`

### 9. Duplicate “Table” landmarks on docs pages with more than one table

- **URL:** `/docs/reviews`, `/docs/configuration`, `/docs/agentic-review`, `/docs/identity`, `/docs/observability`
- **Problem:** axe **moderate** `landmark-unique`: every markdown table is wrapped as `role="region" aria-label="Table"`.
- **Severity:** Low
- **Likely source:** `app/docs/[[...slug]]/page.tsx` (`<ScrollTable label="Table">`); `app/dashboard/scroll-table.tsx`

### 10. Billing docs table has an empty header cell

- **URL:** `https://openreview.tech/docs/billing`
- **Problem:** axe **minor** `empty-table-header` on the leading `<th></th>` of the plans table. First column is the feature name with a blank header.
- **Severity:** Low
- **Likely source:** `docs/billing.md`
- **Evidence:** `docs-billing-table--1280x800.png`

### 11. Landing demo chart labels fail contrast (decorative)

- **URL:** `https://openreview.tech/` at 390×844
- **Problem:** axe **serious** `color-contrast` on `.chart-y-title` / `.chart-x` (3.45:1, 10–11px). Nodes are `aria-hidden="true"` (replica chrome), so this is visual-only.
- **Severity:** Low
- **Likely source:** `app/landing/` replicas / dashboard-look chart CSS in `app/globals.css`

## What looked fine

- **HTTP 200** on `/`, `/docs` (renders Quickstart), all 32 sitemap doc pages, `/changelog`, `/feedback`, `/feedback/roadmap`, `/privacy`, `/terms`, `/security`, `/login`, `/signup`, and both pricing CTA URLs.
- **No broken first-party images.**
- **No document-level overflow** except `/privacy` (issue 2). Docs tables use `ScrollTable` and stay within the viewport.
- **Feedback / roadmap** embed loaded (UserJot board with posts and Planned / In Progress / Completed columns).
- **External link check:** `http://localhost:3000/` in `docs/public/quickstart.md` is an example local URL (expected dead on production). `https://github.com/get-convex/convex-backend/blob/main/self-hosted/docker/docker-compose.yml` returned **429** from GitHub rate limiting, not a confirmed 404.

Heuristic “cut-off” hits on `.sr-only` labels are false positives (screen-reader-only text is clipped on purpose). Heuristic “overlap” hits between adjacent `<code>` spans in markdown, or between the cookie banner and the page, are the same underlying issues 3 and 8 rather than extra bugs.
